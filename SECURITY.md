# 🔒 Política de Seguridad

## Versiones Soportadas

Las siguientes versiones del proyecto reciben actualizaciones de seguridad:

| Versión | Soporte          |
|---------|------------------|
| `main`  | ✅ Activa         |
| Otras   | ❌ Sin soporte    |

---

## 🐛 Reportar una Vulnerabilidad

**Por favor, NO abras un issue público para reportar vulnerabilidades de seguridad.**

Si descubres una vulnerabilidad, sigue estos pasos:

### GitHub Security Advisory

Usa la pestaña **Security** → **Report a vulnerability** de este repositorio para enviar un reporte privado a través de GitHub.

---

## ⏱️ Proceso y Tiempos de Respuesta

| Paso | Tiempo esperado |
|------|-----------------|
| Confirmación de recepción | 48 horas |
| Evaluación inicial | 5 días hábiles |
| Resolución o plan de acción | 30 días |
| Publicación del parche | Según severidad |

---

## 🏆 Reconocimientos

Valoramos enormemente el trabajo de los investigadores de seguridad. Si reportas una vulnerabilidad válida que no haya sido reportada antes, te daremos crédito público (si lo deseas) en:

- El `CHANGELOG.md` del release que soluciona el problema
- La sección de reconocimientos de este repositorio

---

## ⚠️ Scope

Este proyecto actualmente **no** ofrece recompensas económicas (bug bounty). Sin embargo, agradecemos profundamente cada reporte responsable.
